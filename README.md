# 📊 Functional Treat — Student Marks Analysis

## 📌 Project Overview

**Functional Treat** is a beginner-friendly Python project that analyzes the exam marks of students in a class.

The project uses **Python built-in functions and a 1D list (array)** to calculate important statistics such as highest marks, lowest marks, average marks, pass percentage, and grade distribution.

> 🚫 No NumPy or external Python libraries are used.

---

## 🎯 Objectives

* Store student marks in a 1D list.
* Find the total number of students.
* Calculate highest and lowest marks.
* Calculate the average marks.
* Count passed and failed students.
* Calculate the pass percentage.
* Find students who scored exactly 100.
* Sort marks in ascending and descending order.
* Find the second highest and second lowest marks.
* Check whether all students passed using `all()`.
* Check whether any student failed using `any()`.
* Search for a particular mark using `input()` and `in`.
* Display the grade distribution from A to F.

## 💻 How to Run

### 1. Install Python

Make sure Python 3 is installed on your computer.

### 2. Open the Python file

Open:

```text
functional_treat.py
```

using **Python IDLE** or another Python editor.

### 3. Run the program

Run the file using:

```text
Run → Run Module
```

or press:

```text
F5
```

### 4. Enter a mark

The program will ask:

```text
Enter a mark to search:
```

Enter any mark, for example:

```text
89
```

The program will tell you whether that mark exists in the list.
